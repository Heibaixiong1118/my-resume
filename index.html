实现细节与当前边界

工具调用采用自定义 JSON 决策与 Python 分发，未使用模型原生 tool_calls。当前 RAG 返回检索片段，不包含来源引用生成。MCP 为独立的进程内 Client / Server hello(name) 示例，rag_search 与 text_length 未注册为 MCP 工具。Ollama 运行于宿主机，Docker Compose 运行 FastAPI 并持久化 ChromaDB 数据。
